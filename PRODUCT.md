# Product

## Register

product

## Users

Creators, designers, and AI image workflow users who collect prompt examples, generated images, reference images, and process notes for later reuse. They use the site as a personal prompt library: search, filter, add, review, copy, and compare prompts quickly.

## Product Purpose

This product helps users turn scattered AI image prompts into a reusable visual knowledge base. Success means users can find a useful prompt fast, understand why it works, copy it safely, and add new examples without friction.

## Brand Personality

Curated, practical, and visually warm. The interface should feel like a hands-on studio archive rather than a generic admin dashboard.

## Anti-references

Do not turn the product into a generic SaaS landing page, AI-purple gradient interface, heavy glassmorphism shell, or plain spreadsheet-style admin tool. Preserve the current warm paper surface, bold border language, compact visual cards, and handcrafted archive feeling.

## Design Principles

1. Preserve the archive character: keep the existing visual language recognizable while improving clarity and reliability.
2. Make reuse effortless: search, filter, copy, and detail reading should stay obvious and low-friction.
3. Let images lead: prompt examples are visual assets first, so layouts should give generated images enough presence.
4. Keep controls consistent: buttons, form fields, chips, and upload actions should behave predictably across views.
5. Design for imperfect content: empty images, long prompts, missing tags, upload fallback, and sync states should still look intentional.

## Accessibility & Inclusion

Target WCAG AA contrast for body text and controls. Preserve keyboard access for cards and actions, keep focus states visible, avoid motion that blocks task flow, and support reduced-motion preferences where transitions are used.
